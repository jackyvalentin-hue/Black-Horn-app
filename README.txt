BLACK HORN STEAK-BAR — PWA V1

Cette version est une application web installable (PWA) sans abonnement obligatoire.

Fichiers principaux :
- index.html : contenu
- styles.css : design
- app.js : langues + installation
- manifest.webmanifest : configuration PWA
- sw.js : cache hors-ligne
- assets/ : logo
- icons/ : icônes d'application

Pour la tester sur ordinateur :
1. Ouvrir un terminal dans ce dossier.
2. Lancer : python3 -m http.server 8080
3. Ouvrir http://localhost:8080

Pour l'installer réellement sur téléphone, la PWA doit être publiée sur HTTPS (par exemple GitHub Pages gratuitement).
